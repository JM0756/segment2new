Open Play.html for all six games. Choose a game, make progress, and enter “ocean with a robot and a blue palette.” The local command box recognizes catalog keywords and common aliases. It does not call an AI model.
 
Website integration: host Play.html on the same origin as your chat page and embed it in an iframe. Give your model a tool named set_game_theme with optional string fields environment, character and palette. Populate their allowed values from iframe.contentWindow.getGameThemeOptions(). On a tool call, invoke iframe.contentWindow.applyGameTheme(args) after the studio loads. Omitted fields keep their current values. Unknown fields and values throw before applying changes. The function returns the resulting theme. Do not reload the iframe after applying a patch. Example: applyGameTheme({character:'owl',environment:'forest',palette:'amber'}). This direct API is for same-origin integration. No website backend or credentials are included.
 
Visual scope: the player avatar and scene banner appear in every archetype. Orbit Patrol also updates the dock scene, live feed and specimen badges. Specimen shapes and data colors retain their learning meaning. The other five templates use a shared themed setting around their existing minimal puzzle controls. Session theme carries across game selections. Selecting another game starts that game fresh. For edits, change theme.js or the embedded templates and run python3 build.py.
